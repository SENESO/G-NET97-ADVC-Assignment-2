# G-NET97 Advanced C# — Assignment 2: Online Store Order Processing

C# console application implementing an online store order processing system, organized in layers.

## Project Structure

- **Models** — Domain entities (orders, products, customers)
- **Data** — Data access layer
- **Reporting** — Order reports and summaries
- **Search** — Search functionality
- **Common** — Shared helpers and utilities

## How to Run

```bash
dotnet run
```

## Tech Stack

- C# / .NET
- Console Application
